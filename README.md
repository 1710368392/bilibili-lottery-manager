# B站转发抽奖动态管理器

一个油猴（Tampermonkey）脚本，帮你管理因参与转发抽奖而堆积的 B 站转发动态：自动建立台账、追踪开奖、判定中奖，按风险分级后**由你亲手勾选**批量清理。

**v1.0.0 正式版** · 作者：糖心月

## 为什么需要它

经常参与转发抽奖的人，动态列表很快就会被几百条「转发抽奖」刷屏。手动一条条删非常痛苦，而且很容易删错：

- 删了**还没开奖**的转发 → 直接弃权，白参与
- 删了**中了奖**的转发 → UP 主核验转发时找不到，奖品飞了

本脚本把这件事变成「机器分级 + 人工确认」，危险的地方全部锁死。

## 功能

- **扫描建档**：一键读取你的全部转发动态，建立本地台账（数据只存在你自己的浏览器里，不上传任何服务器）
- **核验开奖状态**：逐条调用 B 站官方抽奖接口，自动区分「官方抽奖 / 自发抽奖」，抓取开奖时间、奖品、参与人数
- **自动判定中奖**：对比官方中奖名单，**你中奖的动态自动锁定**；到点后每 60 秒自动复查刚开奖的抽奖，中了立刻弹窗 + 桌面通知告诉你
- **风险分级**：未开奖 / 缓冲期 / 建议删除 / 待确认 / 日期不明，颜色区分，只把真正安全的条目放进删除候选
- **批量清理**：勾选 → 二次确认 → 执行，随时可中止，已完成部分保留
- **加码抽奖识别**：正确处理「UP 主 B 转发 A 的动态并在转发文案里加码抽奖」的场景，A 原抽奖与 B 加码不再误判为重复
- **取关管理**：转发满 30 天的 UP 主进入取关候选，手动挑选手动执行
- **中奖统计页**：参与数 / 中奖数 / 中奖率 / UP 主排行 / 奖品 Top10，支持导出 CSV（Excel 直接打开不乱码）
- **暗黑模式**：自动跟随 B 站 / 系统主题，也可手动固定亮 / 暗
- **面板可拖动**：位置记忆，拖出屏幕自动拉回

## 安全设计（红线）

| 保护 | 说明 |
|---|---|
| 绝不自动删除 | 脚本不会自动删任何东西，每一条都要你亲手勾选 + 二次确认 |
| 未开奖锁死 | 状态为「未开奖」的动态禁止进入删除候选 |
| 中奖锁死 | 检测到你中奖的动态永远锁定 |
| 状态不明不放行 | 开奖日期没核实的条目标「待确认」，删除前额外警告 |
| 缓冲期 | 已开奖未中奖的动态默认等 7 天再列为建议删除 |
| 限速 | 删除间隔 2 秒/条，扫描与查询都有限速，避免触发 B 站风控 |
| 随时中止 | 删除/核验过程中可点「中止」，已完成的部分保留 |

## 安装

1. 安装 [Tampermonkey](https://chromewebstore.google.com/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo) 浏览器插件（Chrome / Edge 均可）
2. 下载本仓库的 `bilibili-lottery-manager.user.js`
3. 把文件**直接拖进浏览器窗口**（或 Tampermonkey 管理面板 → 实用工具 → 导入文件），弹出确认页后点「安装」
4. 打开 B 站并登录，右下角出现粉色「抽奖」圆按钮即安装成功

详细图文说明（含三种安装方式、首次使用两步建档、各功能详解）见 [安装说明.md](./安装说明.md)。

## 快速上手

1. 点右下角「抽奖」按钮 → 点 **「扫描建档」**（十几秒，只收转发类动态）
2. 点 **「核验开奖状态」**（自动判定类型、抓开奖数据、检测是否中奖）
3. 之后挂着 B 站页面就行 —— 开奖到点脚本会自动查结果，中奖立刻通知你
4. 想清理时：筛「建议删除」→ 勾选 → 删除（有二次确认兜底）

## 已知限制

- 依赖 B 站非公开接口，B 站改版可能失效（接口失败时脚本退化为手动标记，不会崩溃）
- 自发抽奖（非官方工具）无接口可查，开奖日期靠文案识别猜测，识别不了的标「待确认」等你手动填
- 浏览器脚本无法后台常驻，自动核验只在 B 站页面开着时工作
